# TradeGuard OSS v0.2.0

Release date: 2026-09-17

## Highlights

TradeGuard OSS v0.2.0 strengthens the journal-analysis contract and adds deterministic machine-readable reporting.

- Versioned CSV journal schema with row-level diagnostics.
- Expanded metrics: profit factor, breakeven trades, best trade, and worst trade.
- Stable `tradeguard.report.v1` JSON envelope.
- CLI report export with `--output`.
- Validation-first behavior: metrics are not emitted for journals with validation errors.
- CI coverage across Python 3.10, 3.11, 3.12, and 3.13.

## Scope

TradeGuard OSS is an analytics and data-quality toolkit. This release does not execute orders, connect to brokerage accounts, or require trading credentials.

## Upgrade

Install the project in editable mode for development:

```bash
python -m pip install -e .
```

Run the test suite:

```bash
python -m pytest
```

Generate a machine-readable report:

```bash
tradeguard examples/sample_journal.csv --json --output report.json
```

## Verification

The release candidate must pass the repository CI workflow before it is merged and tagged.
