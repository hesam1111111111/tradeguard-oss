# TradeGuard OSS v0.16.0

TradeGuard OSS v0.16.0 strengthens the evidence layer and makes the project easier to evaluate, adopt, and review as an actively maintained open-source package.

## Highlights

- adds public `validate_evidence_bundle()` semantic validation;
- fixes Evidence Bundle verification so fingerprint-covered additive top-level members remain compatible;
- formalizes reconciliation, Trial Ledger, and Evidence Bundle v1 compatibility expectations with executable consumer-contract fixtures;
- adds a zero-clone PyPI quickstart;
- adds an executable end-to-end integrity demo from analysis through certification verification;
- adds maintainer-review and OSS-application evidence documentation;
- adds a dated external-evidence snapshot that avoids unsupported adoption claims.

## Compatibility

No existing v1 schema identifier changes in this release. Existing valid report, reconciliation, Trial Ledger, and Evidence Bundle evidence remains within the documented compatibility model.

## Scope

TradeGuard remains an offline/local-file validation and evidence-integrity toolkit. It does not connect to brokers, place trades, attest real execution or identity, or make profitability claims.

## Release gate

Publish only after Python 3.10–3.13 CI, distribution build, and wheel smoke-install validation pass on the release PR.
