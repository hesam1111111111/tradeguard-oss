# Code of Conduct

TradeGuard OSS is intended to be a professional, technical, and welcoming open-source project.

## Expected behavior

- Discuss code, data contracts, tests, and design decisions on their technical merits.
- Be specific, evidence-based, and respectful in reviews and issue discussions.
- Assume good faith while still requiring reproducible evidence for behavioral claims.
- Protect user privacy: never post credentials, private broker exports, account identifiers, or personal financial records.
- Keep security-sensitive details out of public issues when disclosure could create risk.

## Unacceptable behavior

Harassment, personal attacks, discriminatory conduct, threats, doxxing, spam, deliberate disruption, or knowingly publishing another person's sensitive data are not acceptable.

## Enforcement

Maintainers may edit, hide, lock, or remove content and may restrict participation when behavior materially harms contributors, users, project integrity, or security. Enforcement decisions should be proportionate and documented when practical.

## Scope

This code applies to project-managed spaces including issues, pull requests, reviews, discussions, and other official collaboration channels.
